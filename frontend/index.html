Adaptive Baseline Detection Engine

CampusWatch avoids static thresholds. It automatically models circadian human activity profiles to separate normal campus operations from waste.

Diurnal Median Baseline

Learns expected consumption for each hour of the day (00:00 to 23:00) segregated by weekdays vs weekends using 14-day medians.

Dual-Criteria Trigger

Flags consumption only if actual > 2.0x expected AND excess > minimum threshold (100 L or 3 kWh), preventing low-volume false alarms.

Temporal Merging

Merges consecutive anomalous hours (≥ 2 consecutive hours) into a single actionable incident report with cumulative cost and CO2 impact.
